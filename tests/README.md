# اختبارات «رحلة القرآن»

الاختبارات دي بتشغّل اللعبة في متصفح حقيقي (Playwright) على **نسخة اختبار من قاعدة البيانات**:
كل «جهاز» متصفح منفصل، وكلهم بيكلموا خادم اختبار واحد (`fb2/server.cjs`) بيطبّق **نفس ملف قواعد الأمان**
`rules-v15.json`. يعني أي كتابة القواعد الحقيقية هترفضها، بتترفض هنا كمان وبتظهر في قائمة `DENIED`.

> الاختبارات **مش بتلمس Firebase الحقيقي** ولا بيانات المستخدمين. إرسال الإيميلات الفعلي وسلوك متصفح
> الواتساب والآيفون لازم يتجرّبوا يدويًا.

## التشغيل

```bash
npm i playwright            # مرة واحدة (لو مش متثبت)
python3 -m http.server 8765 --bind 127.0.0.1   # من فولدر المشروع، في نافذة لوحدها
bash tests/run-all.sh       # كل الاختبارات
node tests/e2e1.cjs         # أو اختبار واحد
```

متغيّرات اختيارية: `BASE_URL` (افتراضي `http://127.0.0.1:8765`) و `CHROME_PATH` (مسار متصفح Chromium).

## الملفات

| الملف | بيختبر إيه |
|---|---|
| `e2e1.cjs` | **رابط الحلقة بجهازين:** معلمة تسجّل وتعمل حلقة ← طفلة تفتح الرابط وتنضم ← المعلمة تشوفها فورًا ← واجب ← طفل تاني بالكود |
| `e2e2.cjs` | مسابقة حلقة كاملة بين المعلمة والطفلة لحد النتيجة |
| `e2e3.cjs` | تعليق/شيل/رجوع/خروج من الحلقة، دخول المعلمة من جهاز تاني، كلمة سر غلط، «نسيت كلمة السر» |
| `join.cjs` | ١٠ سيناريوهات للدعوة: نت بطيء، نت واقع ثم رجوع، جهاز عليه إخوات، كود غلط، المعلمة تفتح رابطها |
| `modes.cjs` | التسميع، الاستماع والتكرار، طريق الحفظ، المراجعة، ومفيش تمدد أفقي على موبايل ٣٢٠ |
| `play1.cjs` + `player.cjs` | لاعب آلي يكمّل كل نوع لعب للآخر (سورة، جزء، جلسة ذكية، تحدي اليوم، سباق الدقيقة) |
| `crawlN.cjs` + `crawl.cjs` | جولة آلية بتدوس على كل زرار: `node tests/crawlN.cjs kid marah 390 844 5000` |
| `flow.cjs` · `fit.cjs` | شاشة البداية: الخطوات، وإنها ظاهرة كاملة من غير سكرول على ٩ مقاسات |
| `thome.cjs` | لوحة المعلم في صفحة واحدة على الكمبيوتر (حلقة واحدة و٦ حلقات) |
| `owner-photo.cjs` | المالك يفتح كارت المعلم من الجدول ويشوف الصورة والإيميل وأسماء الحلقات |
| `sw-test.cjs` | بدون نت: اللعبة والصور والأدلة شغالة بعد أول زيارة (بيفتح `index.html`) |
| `fb2/` | Firebase وهمي + مُقيِّم قواعد الأمان · `fb/` النسخة الأبسط اللي بيستخدمها `join.cjs` و`flow.cjs` |
| `eslint.config.js` | فحص الكود: استخرج سكربت الصفحة في `inline.js` وشغّل `eslint -c tests/eslint.config.js inline.js` |

## قبل أي نشر

1. `node --check` على سكربت الصفحة + ESLint (مسك متغيّر مكتوب غلط عاش شهور).
2. `bash tests/run-all.sh` — لازم كله ✅ و`DENIED []` و`ERRS []`.
3. انسخ `quran-game.html` إلى `index.html` وزوّد رقم النسخة في `sw.js`.
