# برومبتات رسوم «رحلة القرآن» لجيميناي

الهدف: كل رسوم اللعبة تطلع بنفس روح صورة الأطفال والفانوس اللي اعتمدناها.

## طريقة الشغل (مهمة عشان الروح تفضل واحدة)

1. افتح **شات واحد جديد** في جيميناي وخليك فيه لكل الرسوم. ماتفتحش شات لكل صورة.
2. ارفع **الصورة المعتمدة** (الأطفال التلاتة والفانوس في الجنينة) في أول رسالة.
3. ابعت «رسالة الافتتاح» اللي تحت مرة واحدة.
4. بعد كده ابعت كل برومبت من القوايم لوحده، وكل برومبت يطلّع صورة واحدة.
5. لو صورة طلعت باستايل مختلف، ابعت: `Redo it in exactly the same style as the reference image.`
6. سمّي كل ملف بالاسم المكتوب جنب البرومبت وإنت بتنزّله، وابعتهملي مجموعة مجموعة.

### رسالة الافتتاح (تتبعت مرة واحدة مع الصورة المرجعية)

```
The attached image is the style reference for a children's Quran learning game.
For every image I ask for in this chat, use EXACTLY the same art style as this reference:
soft hand-painted children's storybook look, thick clean dark outlines, smooth gentle
shading, rounded friendly shapes, warm sunny lighting, cheerful vibrant colors
(fresh green, sky blue, warm orange, teal, golden yellow).

Rules for every image in this chat:
- When I mention the boy, the girl, the hijab girl or the lantern, draw the SAME characters
  as in the reference (same faces, hair, skin tone, clothes and colors).
- NO text, NO letters, NO numbers, NO Arabic or English writing anywhere in the image.
- NO watermark, NO logo, NO frame.
- Never draw prophets, angels, or any religious figure. Never draw an open Quran with
  visible writing. Use only nature, objects, animals and ordinary children.
- Friendly and gentle for ages 6 to 12. Nothing scary.
Reply "ready" and wait for my requests.
```

1. **القسم ١ و٢** (الأطفال ونور): أعلى أثر، لأنهم بيظهروا مع كل سؤال.
