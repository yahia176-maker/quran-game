# برومبتات رسوم «رحلة القرآن» لجيميناي

كل برومبت تحت **كامل وجاهز**: دوس زر النسخ اللي على يمين المربع والزقه في جيميناي زي ما هو.

## طريقة الشغل

1. افتح **شات واحد** في جيميناي وخليك فيه لكل الرسوم.
2. في أول رسالة: ارفع **الصورة المعتمدة** (الأطفال التلاتة والفانوس في الجنينة) والزق معاها «رسالة الافتتاح».
3. بعد كده الزق برومبت واحد في كل رسالة. كل برومبت بيطلّع صورة واحدة.
4. نزّل كل صورة وسمّيها بالاسم المكتوب فوق مربعها.
5. لو صورة طلعت باستايل مختلف، ابعت الجملة دي:

```
Redo it in exactly the same style as the reference image.
```

## رسالة الافتتاح (مرة واحدة مع الصورة المرجعية)

```
The attached image is the style reference for a children's Quran learning game. For every image I ask for in this chat, use EXACTLY the same art style as this reference: soft hand-painted children's storybook look, thick clean dark outlines, smooth gentle shading, rounded friendly shapes, warm sunny lighting, cheerful vibrant colors (fresh green, sky blue, warm orange, teal, golden yellow). Rules for every image in this chat: When I mention the boy, the girl, the hijab girl or the lantern, draw the SAME characters as in the reference (same faces, hair, skin tone, clothes and colors). NO text, NO letters, NO numbers, NO Arabic or English writing anywhere in the image. NO watermark, NO logo, NO frame. Never draw prophets, angels, or any religious figure. Never draw an open Quran with visible writing. Use only nature, objects, animals and ordinary children. Friendly and gentle for ages 6 to 12, nothing scary. Reply "ready" and wait for my requests.
```
